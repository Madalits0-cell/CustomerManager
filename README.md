# Customer Manager

JavaFX classroom lab (ICT261 - Lecture 3)

## Features
- Form with Name field and Province ComboBox
- ObservableList of Customer objects
- TableView showing Name and Province
- Input validation
- Add customer
- Confirm before deleting selected customer
- Keyboard support (Enter to add)

## How to run later on PC
1. Open the project folder in VS Code / NetBeans / IntelliJ
2. Make sure JavaFX is configured
3. Run `CustomerManagerApp.java`
